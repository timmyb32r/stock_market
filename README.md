# Контур — лаборатория стратегий российского рынка

Локальный проект: Rust / Axum, Preact / TypeScript / Vite. Бэктесты выполняются на бэкенде; браузер отображает сохранённые результаты. Реальные сделки не отправляются.

## Запуск

Нужны Rust и Node.js с npm. Из корня проекта:

```sh
./scripts/start.sh
```

Откройте http://127.0.0.1:8080. Первая загрузка может занять несколько минут. Прогресс виден в интерфейсе. Для разработки: `cargo run` и в другом терминале `cd web && npm run dev` (Vite проксирует API на порт 8080).

Переменные окружения:

| Имя | По умолчанию | Назначение |
|---|---|---|
| `MARKET_BIND` | `127.0.0.1:8080` | Адрес локального сервера |
| `MARKET_DATA_DIR` | `data` | Папка котировок и результатов |
| `MARKET_WEB_DIR` | `web/dist` | Собранный фронтенд |
| `MARKET_AUTO_REFRESH` | `1` | `0` отключает автоматическую загрузку |

Автообновление работает при запущенном процессе, в 00:15 МСК. После простоя выполняется догрузка. При ошибке нет бесконечного цикла запросов: ручной повтор доступен сразу, автоматический — в следующий день. Текущая незавершённая календарная дата исключается. Результаты и данные сохраняются атомарной заменой JSON-файлов. Обновление котировок догружает последние семь дней и новые записи, не скачивая всю сохранённую историю заново. Промежуточные этапы первой загрузки также сохраняются.

## Стратегии

1. **Следуя за трендом:** две MA по IMOEX, лонг при быстрой выше медленной и шорт при обратном состоянии. Режимы: условный индекс и реальные квартальные фьючерсы MX с целым количеством контрактов. Номинал позиции ограничивается текущим капиталом при входе и проверяется на каждом открытии. Внутридневное изменение экспозиции не моделируется. Свободное обеспечение фьючерсов не приносит процентного дохода.
2. **Тренд с тихой гаванью:** такой же сигнал, переключение IMOEX ↔ LQDT в исследовании и индексный фонд TMOS ↔ LQDT в исполнимом режиме. В настройках можно выбрать загруженный SBMX вместо TMOS.
3. **До дивидендов:** отдельное окно для каждой бумаги, постоянный набор топ-1/2/3, N слотов (по умолчанию перебор 1…14). На вход выделяется `NAV / N`, но не больше свободных денег. Окна и набор бумаг фиксированы на всём периоде одного прогона. Остаток моделируется по доходности LQDT; до доступной истории фонда — по ежедневному начислению исторической ключевой ставки ЦБ. Для LQDT в стратегии 3 используется дробная доля свободного капитала, без округления паёв, как приближение денежного остатка.

Оптимизация — максимальная итоговая доходность с реинвестированием, **без комиссий, проскальзывания и НДФЛ**. Просадка показывается, но не ограничивает поиск. Цена входа и выхода — открытие сессии. Сигнал MA на закрытии доступен только на следующей сессии. При равенстве MA сохраняется предыдущее направление. При достаточно длинной истории начальная позиция определяется состоянием средних на предыдущем закрытии.

По умолчанию перебираются SMA, EMA, WMA, RMA, DEMA, TEMA, HMA, ZLEMA и 23 периода (5…300). Быстрый период строго меньше медленного, всего **16 192 пары**. EMA и RMA инициализируются SMA; DEMA/TEMA последовательно прогревают вложенные EMA. HMA использует половину окна с округлением вниз и корень окна с округлением до ближайшего целого. ZLEMA использует лаг `floor((N−1)/2)`. Дополнительных фильтров и стопов нет.

**Единый результат каждой стратегии:** параметры выбираются по максимальной итоговой доходности на всём периоде с начала 2023 года, затем этот же период прогоняется с выбранными фиксированными параметрами. Последовательной проверки и квартальной смены параметров нет. Кнопка «Пересчитать» повторяет поиск на актуальном ряду. Данные до 2023 года нужны только для прогрева MA (три максимальных периода). Для стратегии 3 более ранние дивидендные события не участвуют в подборе окон. Текущие позиции, таблица сделок и график относятся к тому же выбранному результату. Режимы индекса и реальных инструментов доступны отдельными вкладками; в каждом показано одно значение доходности.

Окна дивидендной стратегии: вход за 5, 10, 15, 20, 30, 40 или 60 торговых дней до первой сессии без дивиденда; выход за 1, 2, 3, 5 или 10 дней. Вход только после публичного объявления суммы и реестра, не раньше следующей сессии после дня объявления. Если объявление запоздало, вход сдвигается; если окно закрыто — сделка исключается. По умолчанию нужно минимум два завершённых события для оценки бумаги.

Сначала каждой бумаге выбирается окно по произведению доходностей её непересекающихся завершённых сделок; по этому показателю бумаги ранжируются. Затем сравниваются топ-1/2/3 рейтинга и варианты N на полноценной симуляции портфеля. **Это максимум в заданной двухэтапной процедуре, а не полный комбинаторный максимум по всем наборам бумаг, окнам и N.** При конфликте одновременных входов приоритет получает более высокая позиция рейтинга. Короткая история и широкий перебор создают риск подгонки; число событий видно рядом с параметрами.

## Источники и ограничения

- [MOEX ISS](https://www.moex.com/a2193): свечи с 2013 года, исторический листинг TQBR, каталог бумаг, спецификации фьючерсов. Выборка включает бумаги, торговавшиеся хотя бы часть периода с 2023 года, включая снятые с торгов. Фонды объединяются по режимам TQTF и TQBR, чтобы учесть миграцию режимов.
- [Smart-Lab: история дивидендов](https://smart-lab.ru/q/SBER/dividend/): размер, реестр и последний день с дивидендом. Универсальный ISS-маршрут `/securities/TICKER/dividends.json` на момент проверки возвращает описание бумаги, поэтому на него не опираемся.
- [ЦБ РФ: ключевая ставка](https://www.cbr.ru/hd_base/KeyRate/): резервное начисление свободного капитала стратегии 3. Процент применяется по календарным дням, включая выходные.
- `sources/dividends.json`: проверенный реестр дат объявлений с отдельной ссылкой на каждое подтверждение. Начальное покрытие — SBER, SBERP, LKOH; у остальных бумаг дивидендная история загружается, но без доказуемой даты объявления они **исключаются** из торговли. Это явное ограничение покрытия, а не отсутствие дивидендов. Реестр можно дополнить импортом; новые даты объявлений автоматически из текста новостей не выводятся.

У части старых источников дата в реестре означает консервативный момент, к которому сумма и реестр точно были публичны (например, утверждение общим собранием), а не самое раннее предварительное сообщение. Неоднозначные ранние объявления не угадываются.

У погашенных фьючерсов ISS может не отдавать STEPPRICE/MINSTEP. Тогда рублёвый множитель подтверждается по нескольким историческим строкам `OPENPOSITIONVALUE / (OPENPOSITION × SETTLEPRICE)` с проверкой стабильности и точности. Если его подтвердить не удалось, контракт исключается. Перекладка — за пять наблюдаемых сессий до экспирации; прибыль от разницы цен двух контрактов не начисляется. В дополнительные сессии выходного дня без свечи MX сделки откладываются до следующего наблюдаемого открытия, позиция отмечается последней доступной ценой. Будущие даты без достаточного календаря не угадываются.

Сплиты, редомициляции и смены тикеров автоматически не склеиваются. Дивидендные бумаги с необработанным скачком цены более чем в 3 раза исключаются из оптимизации. Публичные источники могут иметь пробелы, менять HTML и ограничивать глубину. Если полного ряда нет, соответствующий расчёт помечается недоступным. Доходность реального инструмента не подменяется индексной. Последняя дата ряда и проблемы источников видны в интерфейсе. График IMOEX — ценовой индекс, без дивидендов.

## Импорт и API

На странице «Данные и методика» можно импортировать JSON. Он дополняет кэш: совпавший тикер заменяет инструмент целиком, совпавшие тикер/реестр/сумма заменяют дивидендное событие. Сначала сохраните экспорт, если хотите иметь отдельную резервную копию. Источники должны быть публичными HTTPS-ссылками. Импорт не подтверждает достоверность сторонних данных сам по себе.

```json
{
  "instruments": {},
  "dividends": [{
    "ticker": "SBER",
    "record_date": "2024-07-11",
    "amount": 33.3,
    "declared_on": "2024-04-23",
    "last_buy_date": "2024-07-10",
    "source": "https://smart-lab.ru/q/SBER/dividend/",
    "announcement_source": "https://www.dohod.ru/analytic/research/sberbank-dividendyi-2024"
  }]
}
```

Инструмент: `ticker`, `name`, `kind` (`index`, `fund`, `share`, `future`, `rate`), `source`, `lot_size`, `bars`. Дневная строка: `date` (`YYYY-MM-DD`), `open`, `close`, `volume`. Для фьючерса обязательны `expiry` и `multiplier` (рубли на единицу котировки). Пример полной структуры — экспорт `/api/export`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | Проверка процесса |
| GET | `/api/state` | Результаты, текущая задача, настройки по умолчанию |
| GET | `/api/sources` | Покрытие и дивидендные события |
| GET | `/api/export` | Полный кэш котировок |
| POST | `/api/refresh` | Обновление источников и пересчёт трёх стратегий |
| POST | `/api/strategies/1/recalculate` | Пересчёт стратегии с JSON настроек (`/2`, `/3` аналогично) |
| POST | `/api/import` | Проверка, сохранение данных и пересчёт |

Долгие операции возвращают ответ сразу; прогресс — в `/api/state`. Одновременно выполняется одна операция, повторный запуск получает HTTP 409. Последние успешные результаты доступны во время пересчёта.

## Пассивные ориентиры

На главной странице отдельно показаны «купить и держать» для MCFTR и LQDT с начала 2023 года: итоговая и среднегодовая доходность, просадка и график. MCFTR — индекс полной доходности брутто (дивиденды реинвестируются до налогов), теоретический ориентир, а не торгуемая бумага. Его база — последнее закрытие до первой сессии 2023 года, поскольку индекс публикуется один раз в день, а не имеет реальной цены открытия. LQDT покупается целыми лотами на первом открытии 2023 года, остаток остаётся деньгами. На графиках стратегий добавлена линия MCFTR, LQDT сравнивается по фактическим котировкам без замены ключевой ставкой. Оба источника обновляются вместе с остальными котировками. [Источник индекса: Московская биржа](https://www.moex.com/ru/index/totalreturn/MCFTR).

### Рейтинг Mozgovik (стратегия 4)

Нативная страница и серверный пересчёт модели из `sources/calc.html`: 38 заданных сигналов, перебор N из поля слотов (по умолчанию 1–14). История 25.08.2023–24.07.2026, формулы и ставки исходника сохранены. Это закрытый исторический набор без автоматического получения новых сигналов. Открытые позиции оцениваются по цене входа, акции дробные; формула исходника допускает отрицательный денежный остаток. Ограничения указаны на странице.
